brainmaze-eeg-models
====================

The documentation of **brainmaze-eeg-models** (0.1.0) is maintained with the
package: https://bnelair.github.io/brainmaze-eeg-models/

Ready-to-use trained EEG/iEEG models on ONNX Runtime (CPU or GPU, no PyTorch
needed): seizure probability (the successor of brainmaze-torch's model) and
OpenSpindleNet sleep-spindle detection.

- **Install**: ``pip install brainmaze-eeg-models``
- **Repository**: https://github.com/bnelair/brainmaze-eeg-models
